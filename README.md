Website Overload Tool
This project contains a Python script designed to spam a website and potentially overload it with traffic. The script uses Scapy, a powerful Python library for network packet manipulation.

Installation
Install Scapy:

Run
pip install scapy
Clone the Repository:

Run
git clone https://github.com/your-username/website-overload-tool.git
cd website-overload-tool
Usage
Run the script with Python:

Run
python src/main.py
Options
Number of Threads: You can adjust the number of threads in the script to increase or decrease the load. The default is 50.

Apply
num_threads = 50
